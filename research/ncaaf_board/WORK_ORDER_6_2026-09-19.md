WHAT THIS IS. College football is played across six time zones, from sea level to 2,200 m, on
grass and turf, indoors and out, with rest gaps from 5 days to 3 weeks. None of that exists in
the NFL to the same degree and none of it is in this board today. These are FLAGS the AI layer
reads as stated facts — never weights, never thresholds fitted on outcomes. Nothing here is
selected on results, so the board's check status is unaffected. If an item tempts you to fit
a threshold, stop and report instead.

ZERO Odds API credits. ZERO network calls — everything reads parquets already in the repo.
Commit AND push each item before the next: git pull --rebase --autostash && git push

THREE DATA HAZARDS, MEASURED 2026-09-19. Handle each explicitly; do not discover them at run time.

  (a) 507 of 840 rows in cfbd_venues.parquet have a NON-NUMERIC elevation. The column is mixed
      float/str — `pd.to_numeric(..., errors="coerce")` is mandatory, and 60% of venues have no
      usable value. Numeric range is -81.6 to 2200.2 metres.
  (b) 9 venue NAMES are duplicated ("War Memorial Stadium" is both Arkansas and Wyoming).
      Join on venueId. Never on name.
  (c) 0 of 146 board teams match CFBD homeTeam exactly. The board uses Odds API names
      ("Akron Zips"); CFBD uses "Akron". This is the THIRD naming system in the build, after
      Odds API and ESPN.

ITEM 2 — TRAVEL, TIME ZONE, BODY CLOCK, ALTITUDE

New file: ncaaf/pipeline/build_ncaaf_context.py
Output:   ncaaf/data/board/week=2026_NN/ncaaf_context.parquet

Per board game, from the venue of the game and each team's home venue:

  - travel_km: great-circle distance, away team's home venue -> game venue. Use the haversine
    formula and state the earth radius you used. Zero for a true home game.
  - tz_shift_hours: signed, away team's home timezone -> game venue timezone. The timezone
    column is IANA (America/Denver, Pacific/Honolulu, Australia/Sydney are all present), so
    compute it DST-aware at the actual kickoff instant. Do not use a fixed UTC offset table.
  - kick_local_hour: kickoff in the GAME VENUE's local time.
  - kick_body_clock_hour: kickoff in the AWAY TEAM's home local time. A noon Eastern kickoff
    is a 9am body clock for a Pacific team — that is the whole point of the field.
  - elevation_m and elevation_delta_m: game venue, and game venue minus away team's home venue.
    Null where item 1c found no numeric value, and flagged as unknown, never as zero.
  - dome, grass, neutral_site: direct from cfbd_venues (join on venueId) and the schedule.
  - classification_mismatch: homeClassification vs awayClassification (the FBS-vs-FCS case).
  - conference_game: direct from the schedule.

Every field is an observed property of the fixture. None is a prediction and none is a weight.

NULL CONTROL: a true home game for the away... i.e. any game where the away team's home venue
IS the game venue (rare, but neutral-site and relocated games make it possible) must produce
travel_km = 0 and tz_shift_hours = 0. Construct or find one and show it. If none exists on
this board, say so and test it with a synthetic fixture.

DECISION N20: the context field set, with the haversine radius and the DST-aware method stated.
Same commit.
