ITEM 4 — MARKET MICROSTRUCTURE LAYER (FREE, INDEPENDENT, NO FITTING)

New file: ncaaf/pipeline/market_microstructure.py
Feeds the board built in work order #1 item 2. Reads only the existing line tape.
ZERO credits. ZERO fitting. Nothing here is selected or tuned on outcomes, so this layer does
not touch the board's check status.

Apply the same pre-kick eligibility rule as the board: snapshot_utc < commence_time AND
snapshot_utc <= build_time. Never files[-1].

  4a. PARLAY PRICING AUDIT. For each book, compare its offered parlay/SGP price against the
      product of its own no-vig single-leg probabilities. The difference is that book's
      correlation adjustment plus its parlay tax, computed entirely from prices it publishes.
      Report effective hold by leg count. If work order #1 item 1 found no parlay/SGP market
      keys for NCAAF, report that and compute the leg-count hold curve from single legs only.

  4b. MOVE ORIGINATION. Each row carries book_last_update. For each line change, report which
      book moved first and the lag before others followed. Descriptive only — do NOT fit a
      follow-the-leader rule or a steam threshold. That would be a feature search and the
      standing football rule in CLAUDE.md forbids it.

  4c. STALE-BOOK DETECTION. Flag a book whose book_last_update has not advanced while the
      consensus has moved by more than one point. The NFL line-shopping work found +2.44% fell
      to +1.84% once stale books were excluded and that 50.9% of best numbers sat in three
      books, one offshore. Report the NCAAF equivalents; do not assume they match.

  4d. HOLD BY MARKET. No-vig overround per market per book. Report it; do not act on it.

NULL CONTROL: 4c must flag nothing on a window where every book updated. Construct that
  window from the tape and report zero flags. A detector that fires on everything is not a
  detector.

DECISION N08 or N09 (whichever is next): the microstructure field set and the explicit
statement that none of it is fitted. Same commit.
