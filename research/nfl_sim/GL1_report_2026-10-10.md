# GL1 Report — Game-Line Statistical Baseline & Unanchored Engine (2026-10-10)

## Section 1: Baseline Model + Statistical Control

### Pre-Registrations

**(P1)** On 2021-23 pooled, actual ~ a + b·mkt + c·baseline gives |c_margin| < 0.15
and b within 1 ± 0.15. Public EPA-type models do not add information over the close.

**(P2)** Chosen hl_games lies between 8 and 40 games.

**Null control:** Refit with team ratings permuted across teams within each week;
c must be ≈ 0 (|t| < 1) and corr(baseline, actual) ≈ 0.

### Results

**815 games** across 2021 (272), 2022 (271), 2023 (272). Market lines are consensus
close from nflverse schedules (spread_line, total_line). Not Hard Rock; no price,
no vig; triage only.

**Margin (pooled):**

**Total (pooled):**
- b = 0.820 (SE 0.132), c = +0.149 (SE 0.246, t = +0.61, p = 0.54)

**By season (margin):**

2021 has a negative c (t=−2.25) that reverses in 2022; 2023 is zero. Unstable
across seasons = noise, not signal.

**Reading:** the EPA-based baseline adds zero information over the consensus close.

#### Null control (100 permutations within week)

|--------|------|--------------------|
| c_margin | −0.093 | 0.002 ± 0.116 |
| corr(baseline, actual) | 0.301 | 0.016 ± 0.035 |

Permuted c t-stat = 0.02. All permuted correlations < 0.10.
**NULL CONTROL PASSES.**

#### Baseline model diagnostics

- Residual SD margin: 13.46 points
- Residual SD total: 13.51 points
- corr(baseline_m, actual_m) = 0.301
- corr(baseline_m, mkt_m) = 0.729
- corr(mkt_m, actual_m) = 0.428

The baseline-to-market correlation (0.729) is high, confirming both reflect
the same public EPA signal. The baseline-to-actual (0.301) is lower than
market-to-actual (0.428), confirming the market is a strictly better predictor.

#### Truncation equivalence test

9/9 tests passed:
- 6 (season, week) pairs: features from full data == features from truncated data (byte-identical)
- Negative control: planting a future game changes features (confirms filter is real)

### Summary

The statistical baseline built from public EPA/success ratings and QB EPA, using the
same point-in-time mechanism as the existing rating system, adds no predictive
information over consensus closing lines on 2021-23. This is the expected result
(P1 held) and establishes the bar: any game-line signal from the sim engine must
beat this zero-information baseline, not just correlate with outcomes.
