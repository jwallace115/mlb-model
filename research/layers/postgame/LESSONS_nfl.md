# NFL Post-Game Lessons

Scaffold created 2026-10-11 (PM-1 Item 4, P51). Cowork writes the lessons.

## Format

Each lesson entry:
- **id**: L1, L2, ... (sequential)
- **date_written**: ISO date
- **claim**: one sentence
- **pick_ids**: list of pick_ids that led to this lesson
- **recurrence**: n (how many times the pattern has appeared)
- **teams**: teams involved
- **status**: candidate | active | retired
- **first_slate**: the first slate date this lesson applies to
